Nota ringkas Pengenalan Set

Setiap hentian memberi murid satu kad fakta selepas lulus. Ini kad bagi bab ini:

  • Ahli SetObjek dalam set dipanggil unsur. Unsur boleh apa sahaja: nombor, huruf, warna atau nama murid dalam kelas.
  • Set KosongSet kosong tiada unsur langsung dan ditulis { } atau ∅. Contohnya set hari dalam seminggu yang bermula dengan huruf X.
  • Simbol Unsur∈ dibaca 'ialah unsur bagi' dan ∉ dibaca 'bukan unsur bagi'. Simbol n(A) memberitahu berapa banyak unsur dalam set A.
  • Kira SekaliHuruf dalam perkataan MALAYSIA ada lapan, tetapi n(A) hanya 6 kerana huruf yang berulang dikira sekali sahaja dalam satu set.
  • Susunan Tak Penting{2, 4, 6} dan {6, 4, 2} ialah set yang sama. Susunan dan ulangan unsur tidak mengubah sesebuah set.
  • Set KembarDua set sama apabila setiap unsur set pertama ada dalam set kedua, dan setiap unsur set kedua ada dalam set pertama.
  • Set SemestaSet semesta ξ ialah set semua unsur yang sedang dibincangkan. Dalam gambar rajah Venn, ia dilukis sebagai segi empat.
  • PelengkapA' ialah semua unsur dalam ξ yang bukan unsur A. Jumlah n(A) dan n(A') sentiasa sama dengan n(ξ).
  • SubsetSet kosong dan set A sendiri sentiasa subset bagi A. Set dengan 3 unsur ada 8 subset semuanya.
  • Set KecilSet dengan 4 unsur ada 16 subset. Setiap unsur tambahan menggandakan bilangan subset.
  • Gambar Rajah VennGambar rajah Venn dinamakan sempena John Venn, ahli logik dari England. Segi empat mewakili ξ dan bulatan mewakili set.
  • Reka SendiriGambar rajah Venn yang baik menunjukkan ξ, A, A' dan subset dengan jelas, termasuk bilangan unsur setiap kawasan.

Contoh soalan

5 daripada 54 soalan dalam bab ini. Soalan lain, termasuk soalan berajah, soalan bos dan TP6, dimainkan dalam permainan.

  1. TP1

    Setiap objek dalam sesuatu set dipanggil:

    1. Subset set itu
    2. Unsur
    3. Set semesta
    4. Pelengkap set
    Lihat jawapan

    Jawapan: B. Unsur
    Objek yang menjadi ahli set dipanggil unsur.

  2. TP1

    Set A = {2, 4, 6, 8, 10, 12}, dengan set semesta ξ = {1, 2, 3, ..., 12}. Perihalan set A ialah:

    1. Nombor ganjil
    2. Nombor perdana
    3. Nombor genap
    4. Gandaan 3
    Lihat jawapan

    Jawapan: C. Nombor genap
    Semua unsur A boleh dibahagi dua tanpa baki, jadi A ialah set nombor genap.

  3. TP1

    Set B = {3, 6, 9, 12}, dengan ξ = {1, 2, 3, ..., 12}. Perihalan set B ialah:

    1. Gandaan 4
    2. Gandaan 3
    3. Faktor bagi 12
    4. Nombor ganjil
    Lihat jawapan

    Jawapan: B. Gandaan 3
    3, 6, 9 dan 12 diperoleh dengan mendarab 3 dengan 1, 2, 3 dan 4.

  4. TP2

    Simbol ∈ dalam 3 ∈ A dibaca:

    1. 3 bukan unsur bagi A
    2. 3 ialah subset bagi A
    3. 3 ialah pelengkap bagi A
    4. 3 ialah unsur bagi A
    Lihat jawapan

    Jawapan: D. 3 ialah unsur bagi A
    ∈ bermaksud 'ialah unsur bagi'. ∉ bermaksud 'bukan unsur bagi'.

  5. TP2

    Set A = {1, 3, 5, 7}. Pernyataan yang betul ialah:

    1. 5 ∈ A
    2. 4 ∈ A
    3. 7 ∉ A
    4. 2 ∈ A
    Lihat jawapan

    Jawapan: A. 5 ∈ A
    5 ada dalam senarai A, jadi 5 ∈ A. 4 dan 2 tiada dalam A, dan 7 ada dalam A.

Contoh ulasan PBD

Selepas murid bermain, Jejak TP Matematik mencadangkan TP dan ulasan seperti di bawah. Guru menyemak, kemudian menyalin ulasan ke dalam rekod PBD.

TP1: Murid dapat mengenal set sebagai koleksi objek yang jelas, menghuraikannya dengan perihalan dan penyenaraian, serta mengenal set kosong. Langkah seterusnya ialah menggunakan simbol ∈, ∉ dan n(A).

TP2: Murid memahami tatatanda pembina set, simbol ∈ dan ∉, serta bilangan unsur n(A). Perlu lebih latihan mengira unsur yang berulang sebelum bergerak ke TP3.

TP3: Murid boleh membandingkan dua set dan menerangkan sebab set sama atau tidak sama, termasuk apabila susunan atau ulangan unsur berbeza. Boleh mula menggunakan set semesta dan pelengkap.

TP4: Murid mampu mengenal set semesta dan pelengkap, mewakilkannya dengan gambar rajah Venn, dan mengira n(A') dalam masalah mudah. Seterusnya latih masalah yang melibatkan subset.

TP5: Murid dapat mengenal pasti dan menyenaraikan subset, termasuk set kosong dan set itu sendiri, serta mengira bilangan subset bagi masalah yang lebih kompleks. Sudah bersedia untuk menggabungkan semua konsep set.

TP6: Murid berjaya mereka masalah set sendiri dengan set semesta, set, subset dan pelengkap yang saling berkaitan, lengkap dengan gambar rajah Venn. Pencapaian cemerlang bagi bab ini.

Jimat masa merekod PBD. Murid bermain di telefon, dan jadual TP kelas siap dengan sendirinya.
