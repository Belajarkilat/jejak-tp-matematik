Nota ringkas Fungsi dan Persamaan Kuadratik

Setiap hentian memberi murid satu kad fakta selepas lulus. Ini kad bagi bab ini:

  • Ungkapan KuadratikUngkapan kuadratik dalam satu pemboleh ubah berbentuk ax² + bx + c, dengan a ≠ 0. Kuasa tertinggi pemboleh ubahnya ialah 2.
  • Bentuk ∪ dan ∩Jika a > 0, graf berbentuk ∪ dan ada titik minimum. Jika a < 0, graf berbentuk ∩ dan ada titik maksimum.
  • Banyak kepada SatuFungsi kuadratik ialah hubungan banyak kepada satu: dua nilai x yang berlainan boleh memberi nilai y yang sama, kecuali di titik pusingan.
  • Paksi SimetriPaksi simetri graf ax² + bx + c ialah garis x = −b ÷ 2a. Ia selari dengan paksi-y dan melalui titik pusingan.
  • PuncaPunca persamaan kuadratik ialah nilai x yang menjadikan f(x) = 0. Pada graf, punca ialah titik persilangan graf dengan paksi-x.
  • Sifar DahuluKaedah pemfaktoran hanya sah apabila satu belah persamaan ialah sifar, kerana jika pq = 0, maka p = 0 atau q = 0.
  • Model LuasDengan pagar sepanjang 20 m, lebar x memberi panjang (10 − x). Luas A = x(10 − x) ialah fungsi kuadratik dalam x.
  • Punca yang SahDalam masalah sebenar, semak setiap punca. Panjang, luas dan masa tidak boleh negatif, jadi punca negatif ditolak.
  • Lakar GrafUntuk melakar graf kuadratik, tentukan bentuk (tanda a), pintasan-y (c), punca (jika ada) dan titik pusingan pada paksi simetri.
  • Bingkai GambarMasalah luas berbingkai: luas bingkai = luas keseluruhan − luas gambar. Hasilnya sering persamaan kuadratik.
  • LontaranTinggi objek yang dilambung boleh dimodelkan oleh h(t) = h₀ + vt − 5t². Graf berbentuk ∩ dan titik maksimumnya memberikan tinggi maksimum objek itu.
  • Reka ModelModel matematik yang baik mempunyai pemboleh ubah yang jelas, domain yang munasabah, dan tafsiran bagi setiap nilai penting pada graf.

Contoh soalan

4 daripada 54 soalan dalam bab ini. Soalan lain, termasuk soalan berajah, soalan bos dan TP6, dimainkan dalam permainan.

  1. TP1

    Antara berikut, yang manakah ungkapan kuadratik dalam satu pemboleh ubah?

    1. 3x² − 5x + 2
    2. 3x³ − 5x + 2
    3. x² + y² − 1
    4. 5x − 1
    Lihat jawapan

    Jawapan: A. 3x² − 5x + 2
    Ungkapan kuadratik mempunyai satu pemboleh ubah sahaja dan kuasa tertingginya 2. 3x³ berkuasa 3, x² + y² ada dua pemboleh ubah, dan 5x − 1 linear.

  2. TP1

    Kuasa tertinggi pemboleh ubah dalam suatu ungkapan kuadratik ialah:

    1. 1
    2. 2
    3. 3
    4. 0
    Lihat jawapan

    Jawapan: B. 2
    Perkataan kuadratik berasal daripada kuasa dua. Sebutan x² mesti ada, dan tiada kuasa yang lebih tinggi.

  3. TP1

    Dalam ungkapan 5x² − 3x + 8, nilai a, b dan c ialah:

    1. a = 5, b = 3, c = 8
    2. a = −3, b = 5, c = 8
    3. a = 5, b = −3, c = 8
    4. a = 8, b = −3, c = 5
    Lihat jawapan

    Jawapan: C. a = 5, b = −3, c = 8
    Bandingkan dengan ax² + bx + c. Pekali x² ialah 5, pekali x ialah −3 (termasuk tandanya), dan pemalar ialah 8.

  4. TP2

    Bagi f(x) = x² + bx, apabila b berubah daripada 0 kepada −4, paksi simetri beralih daripada x = 0 kepada:

    1. x = −2
    2. x = 4
    3. x = −4
    4. x = 2
    Lihat jawapan

    Jawapan: D. x = 2
    Paksi simetri x = −b ÷ 2a = −(−4) ÷ 2 = 2. Nilai b mengalihkan graf ke kiri atau ke kanan.

Contoh ulasan PBD

Selepas murid bermain, Jejak TP Matematik mencadangkan TP dan ulasan seperti di bawah. Guru menyemak, kemudian menyalin ulasan ke dalam rekod PBD.

TP1: Murid dapat mengenal pasti ungkapan kuadratik dalam satu pemboleh ubah serta nilai a, b dan c, dan mengetahui bentuk graf ∪ atau ∩. Langkah seterusnya ialah memahami ciri-ciri fungsi kuadratik dan kesan perubahan nilai a, b dan c.

TP2: Murid memahami fungsi kuadratik sebagai hubungan banyak kepada satu, dan dapat menerangkan kesan perubahan a, b dan c ke atas graf. Perlu lebih latihan mencari punca dengan kaedah pemfaktoran.

TP3: Murid boleh menentukan punca persamaan kuadratik dengan kaedah pemfaktoran dan mengaitkannya dengan titik persilangan graf pada paksi-x. Sudah bersedia membentuk fungsi kuadratik daripada situasi.

TP4: Murid mampu membentuk fungsi kuadratik daripada situasi mudah, menyelesaikannya, dan menolak punca yang tidak munasabah. Seterusnya, latih masalah yang memerlukan lakaran graf dan titik maksimum atau minimum.

TP5: Murid dapat melakar graf fungsi kuadratik dan menyelesaikan masalah rutin yang kompleks seperti untung maksimum dan bingkai gambar. Sudah bersedia untuk masalah bukan rutin.

TP6: Murid berjaya mereka situasi sebenar yang dimodelkan oleh fungsi kuadratik, mentafsir titik maksimum dan punca dengan bermakna, serta menilai kemunasabahan jawapan. Pencapaian cemerlang bagi bab ini.

Jimat masa merekod PBD. Murid bermain di telefon, dan jadual TP kelas siap dengan sendirinya.
