Nota ringkas Sukatan Kecenderungan Memusat

Setiap hentian memberi murid satu kad fakta selepas lulus. Ini kad bagi bab ini:

  • Tiga SukatanMod, median dan min ialah tiga cara berbeza untuk mewakili satu set data dengan satu nombor.
  • Data TersusunSebelum mencari median, data mesti disusun dahulu dari kecil ke besar.
  • Tambah dan DarabMenambah nombor sama kepada setiap data menggerakkan min, median dan mod dengan jumlah yang sama. Mendarab pula mengubah kesemuanya mengikut faktor itu.
  • Satu NilaiJika hanya satu nilai berubah, min biasanya berubah tetapi median dan mod boleh kekal sama.
  • Kelas DataKelas dalam jadual kekerapan tidak boleh bertindih dan saiz selangnya mesti sama.
  • Titik TengahMin anggaran menggunakan titik tengah kelas, sebab nilai sebenar setiap data sudah tidak dapat dikesan dalam jadual.
  • Palang TertinggiDalam carta palang, mod ialah nilai pada palang paling tinggi.
  • Batang dan DaunPlot batang dan daun mengekalkan setiap nilai asal, jadi kita boleh membaca mod dan median terus daripadanya.
  • Nilai EkstremNilai ekstrem menarik min ke arahnya, tetapi median dan mod biasanya tidak berganjak.
  • Pilih Yang AdilApabila data mempunyai nilai ekstrem, median selalunya lebih adil untuk mewakili kebanyakan data.
  • JulatJulat ialah nilai terbesar tolak nilai terkecil. Ia menunjukkan betapa tersebarnya data.
  • Hujah BernasHujah yang meyakinkan menggunakan lebih daripada satu sukatan, bukan min sahaja.

Contoh soalan

5 daripada 54 soalan dalam bab ini. Soalan lain, termasuk soalan berajah, soalan bos dan TP6, dimainkan dalam permainan.

  1. TP1

    Mod bagi satu set data ialah nilai yang:

    1. Paling kerap muncul
    2. Berada di tengah selepas disusun
    3. Diperoleh daripada jumlah dibahagi bilangan data
    4. Terbesar tolak terkecil
    Lihat jawapan

    Jawapan: A. Paling kerap muncul
    Mod ialah nilai dengan kekerapan tertinggi.

  2. TP1

    Median bagi satu set data ialah nilai yang:

    1. Paling kerap muncul
    2. Berada di tengah selepas data disusun
    3. Diperoleh daripada jumlah dibahagi bilangan data
    4. Paling besar dalam data
    Lihat jawapan

    Jawapan: B. Berada di tengah selepas data disusun
    Susun data dahulu, kemudian ambil nilai di tengah.

  3. TP1

    Min bagi satu set data dikira dengan:

    1. Nilai yang paling kerap muncul dalam data itu
    2. Nilai di tengah selepas semua data disusun
    3. Jumlah semua nilai dibahagi bilangan data itu
    4. Nilai terbesar tolak nilai terkecil dalam data
    Lihat jawapan

    Jawapan: C. Jumlah semua nilai dibahagi bilangan data itu
    Min = jumlah nilai ÷ bilangan data.

  4. TP2

    Apabila setiap nilai ditambah dengan nombor yang sama, min, median dan mod:

    1. Ketiga-tiganya bertambah dengan nombor itu
    2. Min berubah, median dan mod kekal
    3. Mod berubah, min dan median kekal
    4. Ketiga-tiganya kekal sama seperti asal
    Lihat jawapan

    Jawapan: A. Ketiga-tiganya bertambah dengan nombor itu
    Seluruh set data bergerak sama jauh, jadi ketiga-tiga sukatan bergerak sama jauh.

  5. TP2

    Apabila setiap nilai didarab dengan 3, min baharu ialah:

    1. Min asal tambah 3
    2. 3 kali min asal
    3. Min asal dibahagi 3
    4. Sama dengan min asal
    Lihat jawapan

    Jawapan: B. 3 kali min asal
    Mendarab semua nilai dengan 3 mendarabkan jumlah dengan 3, jadi min juga didarab dengan 3.

Contoh ulasan PBD

Selepas murid bermain, Jejak TP Matematik mencadangkan TP dan ulasan seperti di bawah. Guru menyemak, kemudian menyalin ulasan ke dalam rekod PBD.

TP1: Murid dapat mengenal mod, min dan median serta mencarinya bagi data tak terkumpul yang mudah. Langkah seterusnya ialah memahami bagaimana ketiga-tiga sukatan berubah apabila data berubah.

TP2: Murid memahami mod, min dan median serta kesan menambah atau mendarab data terhadapnya. Perlu lebih latihan sebelum bergerak ke TP3.

TP3: Murid boleh membina jadual kekerapan bagi data terkumpul serta menentukan kelas mod dan min anggaran. Galakkan menyemak jumlah kekerapan sama dengan bilangan data.

TP4: Murid mampu menyelesaikan masalah rutin yang mudah dengan membaca mod, min dan median daripada jadual, carta palang dan batang dan daun. Seterusnya latih mentafsir nilai ekstrem.

TP5: Murid dapat memilih sukatan yang sesuai dan menjustifikasikannya apabila data mempunyai nilai ekstrem. Sudah bersedia untuk membanding dua set data.

TP6: Murid berjaya membanding dua set data dengan min, median dan julat, dan membina hujah yang meyakinkan. Pencapaian cemerlang bagi bab ini.

Jimat masa merekod PBD. Murid bermain di telefon, dan jadual TP kelas siap dengan sendirinya.
