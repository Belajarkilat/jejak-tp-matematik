Nota ringkas Operasi Set

Setiap hentian memberi murid satu kad fakta selepas lulus. Ini kad bagi bab ini:

  • PersilanganPersilangan A ∩ B ialah set unsur yang sepunya bagi A dan B. Dalam gambar rajah Venn, ia ialah kawasan bertindih.
  • KesatuanKesatuan A ∪ B ialah set semua unsur yang berada dalam A atau B atau kedua-duanya.
  • Kawasan VennDalam gambar rajah Venn tiga set, ada lapan kawasan. Untuk mencari n(suatu operasi), jumlahkan bilangan dalam setiap kawasan yang berlorek.
  • Tepat Dua"Tepat dua" bermaksud dalam dua set sahaja, iaitu tiga kawasan yang bertindih dua tanpa kawasan tengah A ∩ B ∩ C.
  • Kurungan DahuluBagi gabungan operasi set, selesaikan operasi dalam kurungan dahulu, kemudian operasi di luar kurungan.
  • Tulis UngkapanKawasan "dalam C tetapi bukan dalam A dan bukan dalam B" ditulis C ∩ (A ∪ B)′.
  • Tinjauann(A ∪ B) = n(A) + n(B) − n(A ∩ B). Bilangan murid yang tidak berada dalam A atau B = n(ξ) − n(A ∪ B).
  • Isi dari TengahDalam masalah tinjauan, mulakan dengan kawasan persilangan, kemudian isi kawasan "sahaja", dan akhir sekali kawasan di luar.
  • Tepat Satu"Tepat satu" bermaksud dalam satu set sahaja, iaitu kawasan A sahaja, B sahaja dan C sahaja.
  • Sekurang-kurangnya"Sekurang-kurangnya dua" = tepat dua + tepat tiga. Baca kata kuantiti dengan teliti sebelum melorek.
  • Julat xBagi n(ξ), n(A) dan n(B) yang diberi, n(A ∩ B) paling kecil apabila tiada murid di luar A ∪ B, dan paling besar apabila set yang lebih kecil berada sepenuhnya dalam set yang lebih besar.
  • Pereka TinjauanTinjauan yang baik mempunyai soalan jelas, set yang ditakrif dengan tepat, dan data yang boleh diwakili dengan gambar rajah Venn.

Contoh soalan

4 daripada 54 soalan dalam bab ini. Soalan lain, termasuk soalan berajah, soalan bos dan TP6, dimainkan dalam permainan.

  1. TP1

    Persilangan set A dan set B ialah set yang mengandungi unsur yang:

    1. Berada dalam A atau B
    2. Berada dalam ξ tetapi bukan dalam A
    3. Berada dalam A tetapi bukan dalam B
    4. Sepunya bagi A dan B
    Lihat jawapan

    Jawapan: D. Sepunya bagi A dan B
    Persilangan = unsur sepunya. Unsur dalam A atau B ialah kesatuan.

  2. TP1

    Diberi P = {a, b, c, d} dan Q = {c, d, e}. Set P ∩ Q ialah:

    1. {c, d}
    2. {a, b, c, d, e}
    3. {a, b}
    4. {e}
    Lihat jawapan

    Jawapan: A. {c, d}
    Unsur sepunya bagi P dan Q ialah c dan d.

  3. TP2

    Pelengkap bagi persilangan, iaitu (A ∩ B)′, ialah:

    1. Unsur yang berada dalam A dan B
    2. Unsur ξ yang tidak berada dalam A ∩ B
    3. Unsur yang tiada dalam A dan tiada dalam B
    4. Unsur dalam A tetapi bukan dalam B
    Lihat jawapan

    Jawapan: B. Unsur ξ yang tidak berada dalam A ∩ B
    Pelengkap ialah semua unsur dalam set semesta yang tidak berada dalam set itu. Pilihan ketiga ialah (A ∪ B)′.

  4. TP2

    Mengapakah n(A ∩ B) ditolak dalam rumus n(A ∪ B) = n(A) + n(B) − n(A ∩ B)?

    1. Nilai n(A ∩ B) lebih besar daripada n(A)
    2. Unsur A ∩ B tiada dalam A ∪ B
    3. Unsur A ∩ B dikira dua kali dalam n(A) + n(B)
    4. Supaya jawapan menjadi nombor genap
    Lihat jawapan

    Jawapan: C. Unsur A ∩ B dikira dua kali dalam n(A) + n(B)
    Dalam Rajah 1, n(A) = 13 dan n(B) = 11. 13 + 11 = 24 mengira 5 murid A ∩ B dua kali, jadi n(A ∪ B) = 24 − 5 = 19.

Contoh ulasan PBD

Selepas murid bermain, Jejak TP Matematik mencadangkan TP dan ulasan seperti di bawah. Guru menyemak, kemudian menyalin ulasan ke dalam rekod PBD.

TP1: Murid dapat menentukan persilangan dua set dan pelengkapnya menggunakan penyenaraian, tatatanda pembina set dan gambar rajah Venn. Langkah seterusnya ialah kesatuan set.

TP2: Murid memahami kesatuan dan persilangan set serta pelengkapnya, dan dapat membaca bilangan unsur daripada gambar rajah Venn tiga set. Perlu lebih latihan gabungan operasi set.

TP3: Murid boleh menentukan gabungan operasi set seperti (A ∪ B) ∩ C dengan menyelesaikan kurungan dahulu, dan menulis ungkapan bagi kawasan yang berlorek.

TP4: Murid mampu menyelesaikan masalah tinjauan dua set menggunakan n(A ∪ B) = n(A) + n(B) − n(A ∩ B). Seterusnya, latih masalah tiga set dengan kata kuantiti seperti "tepat" dan "sekurang-kurangnya".

TP5: Murid dapat menyelesaikan masalah rutin yang kompleks melibatkan tiga set dan gabungan operasi set. Sudah bersedia untuk masalah bukan rutin.

TP6: Murid berjaya mereka tinjauan sendiri dengan data yang konsisten, mewakilkannya dengan gambar rajah Venn, dan menaakul tentang julat nilai persilangan. Pencapaian cemerlang bagi bab ini.

Jimat masa merekod PBD. Murid bermain di telefon, dan jadual TP kelas siap dengan sendirinya.
